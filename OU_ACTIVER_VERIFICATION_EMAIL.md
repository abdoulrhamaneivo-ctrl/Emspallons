# 📍 Où Activer la Vérification d'Email dans Supabase

## 🎯 Vous Êtes Actuellement Ici

**Page actuelle** : `/auth/providers?provider=email`
**Section** : Configuration Email (providers)

**⚠️ Cette section ne contient PAS l'option "Enable email confirmations"**

---

## ✅ Où Aller : Auth Settings

### Étape 1 : Aller dans Auth Settings

**Option A : Depuis la barre latérale**

1. **Dans le menu gauche** de Supabase Dashboard
2. **Cliquer sur** : **"Authentication"** ou **"Auth"** (icône de cadenas)
3. **Cliquer sur** : **"Settings"** ou **"Paramètres"** (sous-menu)
4. **OU directement** dans la barre d'onglets en haut

**Option B : URL Directe**

**Aller directement sur** : https://supabase.com/dashboard/project/zmptirvzmoxprshxiezb/auth/settings

---

## ✅ Étape 2 : Trouver "Enable email confirmations"

### Dans la Page Auth Settings

**Chercher la section** :
- **"Email Auth"** ou
- **"Email Configuration"** ou
- **"Email Settings"** ou
- **"Confirmations"**

### Options à Activer

**Chercher ces options** :

1. **"Enable email signups"** ou **"Activer les inscriptions par email"**
   - ✅ **ACTIVÉ** (toggle vert)

2. **"Enable email confirmations"** ou **"Activer les confirmations email"**
   - ✅ **ACTIVÉ** (toggle vert) ← **C'EST CE QU'IL FAUT !**

3. **"Require email confirmation"** ou **"Exiger la confirmation email"**
   - ✅ **ACTIVÉ** (toggle vert)

---

## 🔍 Si Vous Ne Trouvez Pas

### Vérifier les Différentes Sections

**Dans Auth Settings, vérifier** :

1. **Section "Email Auth"** :
   - Chercher "Enable email confirmations"
   - Toggle à activer

2. **Section "Confirmations"** :
   - Chercher "Email confirmations"
   - Toggle à activer

3. **Section "Settings"** :
   - Défiler vers le bas
   - Chercher les options email

### Alternative : Chercher dans le Menu

1. **Menu gauche** → **"Authentication"**
2. **Sous-menu** → **"Settings"** ou **"Configuration"**
3. **Onglets** : Chercher un onglet "Settings" ou "Email Settings"
